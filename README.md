# Renewable Energy Prediction Using Machine Learning

## Project Overview
This project focuses on predicting solar energy generation using weather and solar radiation data with Machine Learning techniques.

## Objectives
- Analyze renewable energy data.
- Understand the impact of weather conditions on solar energy generation.
- Predict solar energy generation using Machine Learning.
- Compare the performance of different models.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
1. Linear Regression
2. Random Forest Regressor
3. MLP Neural Network

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the Python file:

   `python renewable_energy_project.py`

## Project Outcome
The project compares multiple Machine Learning models to understand their performance in predicting solar energy generation.
